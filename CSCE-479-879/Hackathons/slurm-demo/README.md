Ths SLURM script uses demo_slurm.py. Replace it with any other script of your choice.
The script uses csce_gpu and csce_gpu_preempt, csce_gpu partitions that allows only one job at a time. If you would like to submit more than one job (which we encourage generally), you can submit the extras to the csce_gpu_preempt partition by substituting in the line #SBATCH --partition=csce_gpu_preempt. More infomration on available partitions available at [here](https://hcc.unl.edu/docs/submitting_jobs/partitions/swan_available_partitions/).
You can submit an unlimited number of jobs to the csce_gpu_preempt queue, but they may be interrupted anytime another student needs a gpu on the cse420 partition and there are no others available. Thus, we reccomend saving your model periodically so that you can restart training from where it was interrupted rather than having to start all over again. Other partitions on swan are available, including gpu and guest_gpu.
